# Networkwalks Cybersecurity Internship

This repository contains practical cybersecurity projects and technical documentation completed as part of my **Cybersecurity & Ethical Hacking Internship at Networkwalks**.

## Week 2 – Cybersecurity Labs

During Week 2, I worked on two practical modules:

### 1. Footprinting with Multiple Tools
Hands-on practice with reconnaissance and information gathering using different cybersecurity tools.

Practical network discovery and scanning to identify active hosts and analyze network information.
