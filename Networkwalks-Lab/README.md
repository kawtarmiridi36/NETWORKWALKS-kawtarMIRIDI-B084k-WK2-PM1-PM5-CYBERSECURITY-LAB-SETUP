# Week 2 – Cybersecurity & Ethical Hacking Labs

This repository documents the practical tasks completed during **Week 2** of my Cybersecurity & Ethical Hacking Internship at **Networkwalks**.

## 📌 Project Modules

### 1. Footprinting with Multiple Tools
Practical footprinting and reconnaissance exercises using multiple tools to gather information about a target domain.

### 2. Network Scanning with Zenmap
A practical network scanning exercise using Zenmap, the graphical interface for Nmap, to identify live hosts on a local network and visualize the network topology.

## 🛠️ Tools Used

- Kali Linux
- WHOIS
- WhatWeb
- Nslookup
- cURL
- WAFW00F
- DNSRecon
- Zenmap / Nmap

## 📂 Repository Structure

- `Footprinting/` – Footprinting task documentation, results and screenshots.
- `Network-Scanning-Zenmap/` – Network scanning documentation, results, screenshots and topology.

## 🎯 Objective

To complete the assigned practical cybersecurity tasks and document their results as part of my hands-on internship experience.
